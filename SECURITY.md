# Sécurité

Merci de ne pas signaler une faille de sécurité dans un ticket public.

Utilisez plutôt le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**.
Décrivez le problème et, si possible, comment le reproduire. Une réponse sera apportée dès que possible.

Ce projet est un jeu statique sans serveur ni compte : aucune donnée personnelle n'est collectée.
Les protections en place sont résumées dans le [README](README.md#sécurité-et-vie-privée) ; la règle de relecture des
chapitres (un chapitre est du code exécuté par le jeu) est rappelée dans [CONTRIBUTING.md](CONTRIBUTING.md).
